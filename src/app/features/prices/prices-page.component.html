Anthropic API key and exact token counts

Your own Anthropic API key is used for flows that call Anthropic models and for exact token counts. It is kept in the OS keyring and only sent to Anthropic. Token counts are estimates by default. With an Anthropic API key you can replace the estimate of a message with the exact count: use Count exactly in the inspector. That sends the message's content (secrets masked) to Anthropic's token counting endpoint, only when you click. The key is kept in the OS keyring.
