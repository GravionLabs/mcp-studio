Providers

Flows call language models through these providers. The model of an LLM step picks one: a plain name such as claude-sonnet-5-5 is Anthropic, openai:gpt-4o uses the OpenAI-compatible endpoint, and ollama:llama3.1:8b uses local Ollama. API keys are kept in the OS keyring and only sent to their provider.
