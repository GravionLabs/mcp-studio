Clients

Send the traffic of a server in Claude Desktop, Claude Code, VS Code, the GitHub Copilot CLI or OpenCode through MCP Studio, to see every message in the inspector. MCP Studio changes only that entry in the client's configuration file, keeps a copy of the file, and can put the original back. The client has to be restarted after a change. A routed server only works while MCP Studio is running.
