OpenTelemetry export

Send spans to an OpenTelemetry collector or backend such as Jaeger, Tempo, or Langfuse (OTLP over HTTP, JSON). Only names, timing, status, and estimated token counts are sent, never arguments or results. Off by default; turning it on sends only spans recorded afterwards.

Headers, for example an API key (secret values are kept in the OS keyring)
